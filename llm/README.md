# LLM Notes

This directory contains notes produced by the assistant about repository changes, design decisions, and image/style guidelines. The assistant will continue to add short, focused markdown files here as it works on the project.

Purpose:
- Record decisions about data model changes (e.g., `src/template/data.php`).
- Summarize visual style and sample images.
- Track outstanding validation tasks and next steps.

Conventions:
- Filenames are kebab-case and descriptive (e.g. `images-inspection.md`).
- Keep entries concise (one page) with date and brief bullets.

If you want a different structure, tell me and I'll adapt future notes.
